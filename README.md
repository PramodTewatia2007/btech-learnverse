# BTech LearnVerse — Learn Everything From Zero

> **A Complete Beginner-Friendly, Interactive, Multisubject Learning Platform for B.Tech Engineering Students**

---

## 🌟 Vision & Educational Philosophy

Many students entering B.Tech engineering programs struggle with abstract technical jargon, complex mathematical equations, programming pointer logic, and laboratory calculations. Traditional textbooks assume prior knowledge and promote rote memorization.

**BTech LearnVerse** is engineered as a patient, personal engineering tutor that explains every concept from absolute scratch using an empathetic **12-Step Pedagogical Methodology**, real-world analogies, interactive 2D/3D physics & circuit simulations, virtual laboratory experiments with observation recording, step-by-step solved university numericals, and adaptive multilingual explanations (**Simple English, Hinglish, and Hindi**).

## 🎓 The 12-Step Pedagogical Methodology

Every theoretical lesson follows this structured journey:
1. **Step 1: Real-Life Question (Curiosity Trigger)** — Starts with a tangible real-world phenomenon (e.g., *"Why do soap bubbles show colorful swirls?"*).
2. **Step 2: Simple Plain-Language Explanation** — Unravels the answer in friendly, approachable sentences.
3. **Step 3: Familiar Everyday Analogy** — Connects the concept to an intuitive mental model while clearly noting its physical limitations.
4. **Step 4: Formal Technical Terminology** — Introduces standard engineering vocabulary and precise definitions.
5. **Step 5: Visual Demonstration & Simulation** — Embeds interactive 2D/3D physics, circuit, optical, or code simulations.
6. **Step 6: Student Experimentation** — Sliders, dials, and interactive inputs let students manipulate physical variables and observe real-time consequences.
7. **Step 7: Underlying Scientific / Engineering Principle** — Explains the fundamental laws (Faraday, Maxwell, Stokes, Ohm, de Broglie).
8. **Step 8: Mathematical Formula Breakdown** — Typeset with LaTeX/KaTeX, explaining every symbol and standard SI units.
9. **Step 9: Step-by-Step Worked University Example** — Complete numerical solution with given data, formula substitution, and units.
10. **Step 10: Common Mistakes & Misconceptions Warning** — Highlights frequent exam errors and their corrections.
11. **Step 11: Adaptive Practice Checkpoints** — Beginner, Intermediate, and Advanced multiple-choice questions with hints and instant feedback.
12. **Step 12: Lesson Summary & Exit Assessment Quiz** — Bulleted takeaways and a scored exit quiz with celebration confetti upon mastery.

## 🔬 Interactive Simulations & Visualizers Built-in

- **Wave Optics & Interferometry (`Optics3DSimulation`)**:
  - Thin Film constructive/destructive interference with thickness and refractive index sliders.
  - Newton's Rings apparatus with lens curvature slider, wavelength selector, and dark center verification.
  - Fraunhofer Single/Double Slit diffraction intensity envelope and fringe generator.
  - Michelson Interferometer mirror translation and fringe counting.
- **Lasers & Optical Fibers (`LaserFiber3DSimulation`)**:
  - Optical fiber core/cladding ray tracing with acceptance cone and total internal reflection (TIR) leakage detector.
  - 3-level Ruby laser vs 4-level He-Ne gas laser population inversion and stimulated emission.
  - Step-index zig-zag ray paths vs graded-index (GRIN) sinusoidal helical refraction comparison.
- **Circuits & Resonance (`CircuitSimulator`)**:
  - Series vs Parallel DC circuit solver with live Ohm's law, node voltages, and KCL branch currents.
  - Series RLC resonance curve with adjustable $R$, $L$, $C$, and $f$, displaying resonant frequency $f_0$, quality factor $Q$, and power factor.
  - Semiconductor diode forward V-I characteristics comparing Silicon ($0.7\,\text{V}$) vs Germanium ($0.3\,\text{V}$) knee voltages.
- **Quantum Mechanics (`QuantumSimulation`)**:
  - Vacuum phototube photoelectric effect with cathode work functions (Cesium, Zinc, Copper), variable wavelength, and retarding stopping potential $V_0$.
  - de Broglie matter wave-packet with momentum spread $\Delta p$ illustrating the Heisenberg Uncertainty Principle ($\Delta x \cdot \Delta p \ge \hbar/2$).
- **Transformers & Induction Motors (`TransformerMotor3DSimulation`)**:
  - Single-phase transformer laminated core with animated mutual magnetic flux loops, turns ratio $k = N_2/N_1$, and primary/secondary volt-ampere calculations.
  - 3-phase induction motor rotating magnetic field (RMF) and squirrel cage rotor slip speed $N_r = N_s(1 - s)$.
- **C Code & Memory Tracer (`CCodePlayground`)**:
  - Safe client-side sandbox with line-by-line step execution, pointer dereference tracing, and RAM stack memory inspector.
- **Calculus & Function Grapher (`MathGrapher`)**:
  - Real-time function plotter with draggable tangent line derivative slope $f'(x_0)$ and definite integral Riemann shaded area under curve.
- **Environmental & Ecological Simulator (`EnvironmentalSimulator`)**:
  - Lindeman's 10% trophic energy transfer pyramid from solar radiation to apex predators.
  - Personal carbon footprint calculator with tree offset requirements.
- **English Communication Trainer (`EnglishAudioTrainer`)**:
  - IPA phonetic consonant/vowel cards with real-time Web Speech API audio synthesis and syllable stress rules.

## 🌐 Multilingual & Accessibility Features

- **3 Language Modes**:
  1. **Simple English (`en`)**: Clean, accessible international English.
  2. **Hinglish (`hinglish`)**: Conversational Hindi-English blend with standard English technical terms.
  3. **Hindi (`hi`)**: Hindi explanations maintaining standardized English engineering symbols and equations.
- **Font Scaling**: Standard (14px), Medium (16px), and Large (18px).
- **Text-to-Speech (TTS)**: Built-in hands-free Web Speech API read-aloud support.
- **Personal AI Tutor**: Context-aware engineering doubt solver connected to the backend Express server with step-by-step analogies and misconception warnings.
- **Keyboard Shortcuts**: `Ctrl + K` opens the universal search modal.

## 🚀 Getting Started

### 1. Prerequisites
- Node.js (v18 or higher; tested on v24)
- npm (v9 or higher)

### 2. Installation
Clone the repository and install dependencies:
```bash
git clone <repository-url>
cd <project-folder>
npm install
```

### 3. Run Development Server (Frontend + Express API Server)
Start both the Vite dev server and the Express API server concurrently:
```bash
npm run dev
```
- **Web App**: `http://localhost:5173`
- **Express API Server**: `http://localhost:5000`

### 4. Build for Production
To typecheck and compile the production bundle:
```bash
npm run build
```
Production assets are generated in the `dist/` directory.
